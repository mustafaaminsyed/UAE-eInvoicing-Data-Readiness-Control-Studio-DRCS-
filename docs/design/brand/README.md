# Brand assets

Upload Dariba logos, brand guidelines, color references, and typography references here.

For third-party marks, note the owner, source URL, download date, and permitted use. Do not
move an asset into `src/assets/` until it is approved for production use.

## Approved reference

### `daribatech-green-corporate-wordmark.png`

- Role: canonical DaribaTech corporate wordmark supplied by the project owner.
- Best use: light or white backgrounds with generous clear space.
- Do not use as the compact DRCS product lockup shown in the landing-page hero reference.
- A transparent, light-on-dark source asset should be supplied before this mark is used on
  dark emerald surfaces; CSS inversion is not the canonical brand treatment.
