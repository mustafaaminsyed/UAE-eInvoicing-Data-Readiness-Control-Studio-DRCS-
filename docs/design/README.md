# DRCS design reference library

Use this directory for design inputs and historical references. Files stored here are not
automatically shipped with the application.

## Upload locations

- `brand/` — Dariba logos, brand guidelines, and approved identity assets.
- `references/landing-page/` — landing-page screenshots, mockups, and visual direction.
- `references/dashboard/` — dashboard screenshots, mockups, and visual direction.

Use lowercase, descriptive filenames with hyphens, for example:

- `dariba-logo-light.svg`
- `landing-page-emerald-direction-2026-10.png`
- `executive-dashboard-reference-2026-10.png`

For externally sourced assets, record the source, date, usage permission, and intended
use in the nearest folder README. Keep MoF, FTA, Peppol, and other third-party marks as
references until their use has been reviewed and approved.

Production assets imported by React should remain under `src/assets/`.
