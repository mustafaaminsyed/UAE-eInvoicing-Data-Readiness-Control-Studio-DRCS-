## Current visual direction

### `daribatech-branding-hero-reference.jpeg`

Use this as the primary landing-page composition reference. It establishes:

- a dark emerald hero with a mint primary action and white secondary action;
- a compact light-on-dark `Dariba DRCS` product lockup, distinct from the corporate
  DaribaTech wordmark;
- a two-column hero with product messaging on the left and an angled dashboard preview on
  the right;
- restrained geometric UAE visual cues that support rather than compete with the product;
- a white four-capability strip immediately below the hero;
- a four-step workflow followed by a pale-mint regulatory coverage panel;
- compact enterprise typography, limited status colors, and generous horizontal spacing;
- MoF, FTA, and Peppol references as alignment context only, never as endorsement.

Any sample dashboard figures must be visibly identified as illustrative unless sourced from
the active DRCS workspace.
